## Fernando Pinto

I build web systems end to end — the API, the front end, the database and the
containers they run in. What holds my attention is the part that decides whether

revoked, and how much it costs to change any of it six months later.

Based in Porto, Portugal.

### What I'm building

**[anvil](https://github.com/fernandosilvapinto/anvil)** — A self-hosted
OpenID Connect identity provider on Keycloak. Single sign-on and permission-based
authorization shared by independent applications, with every registration
expressed as a versioned script instead of a sequence of console clicks.

**[pistachio-api](https://github.com/fernandosilvapinto/pistachio-api)** — The
API behind a platform for selling and scheduling services, built to stay agnostic
to the business that uses it. ASP.NET Core, Entity Framework Core, PostgreSQL,
with two React front ends
([admin](https://github.com/fernandosilvapinto/pistachio-admin),
[storefront](https://github.com/fernandosilvapinto/pistachio-client)).

**CARGA** — Draft survey and bulk cargo loading for ships: how much cargo a
vessel has taken on, derived from how deep it sits in the water. A rebuild of an
earlier PHP system on .NET and React. Private while it is being finished.
